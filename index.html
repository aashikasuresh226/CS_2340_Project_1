project description

GT Movies Store

A Django-based web app that lets registered users:

  • View a list of movies
  • Search movies by title
  • Read, create, edit, and report reviews before making a selection
  • Add movies to their cart and purchase them

Plus:

  • Fully responsive — accessible across different devices and screen sizes
  • Admin view: create, update, delete, and manage users, reviews, orders, and movies
